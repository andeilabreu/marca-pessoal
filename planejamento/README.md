# Planejamento de retorno ao mercado

Este documento organiza as etapas do planejamento. Ele não define respostas
por Andeil; cada etapa será preenchida somente com informações confirmadas.

## Etapa 1 — Conhecer o ponto de partida

- [x] Registrar histórico profissional inicial.
- [x] Registrar formação e cursos iniciais.
- [ ] Complementar nomes, instituições e períodos dos cursos quando possível.
- [ ] Detalhar conhecimentos e experiências atuais.
- [x] Identificar recursos, restrições e tempo disponível.
- [ ] Revisar e finalizar o currículo, reconstruir o LinkedIn e avaliar o
  GitHub.

## Etapa 2 — Explorar as áreas de interesse

- [ ] Entender a rotina de suporte de sistemas.
- [ ] Entender a rotina de qualidade de software.
- [ ] Entender a rotina de desenvolvimento de software.
- [ ] Comparar requisitos de entrada, afinidade e oportunidades.
- [x] Escolher uma prioridade inicial sem descartar alternativas: qualidade de
  software.

## Etapa 3 — Definir o posicionamento

- [ ] Identificar experiências e qualidades que podem ser demonstradas.
- [ ] Definir público e tipos de vaga desejados.
- [ ] Criar uma apresentação profissional verdadeira e clara.
- [ ] Planejar currículo, LinkedIn e presença profissional.

## Etapa 4 — Preparar a entrada no mercado

- [x] Criar um plano de estudos compatível com o objetivo escolhido.
- [ ] Definir formas simples de demonstrar aprendizado e capacidade.
- [ ] Preparar candidaturas e entrevistas.
- [ ] Criar uma rotina sustentável de busca por vagas e contatos.

## Etapa 5 — Acompanhar e ajustar

- [ ] Registrar ações realizadas e respostas recebidas.
- [ ] Avaliar o progresso periodicamente.
- [ ] Ajustar a estratégia usando fatos e resultados.
